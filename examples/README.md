# Examples

This directory is split into concept showcases and runnable real-world CLIs.

Use `concepts/` when you want focused examples of one part of the framework.

- `concepts/output-patterns.ts`
- `concepts/prompt-patterns.ts`
- `concepts/theme-showcase.ts`

Use `real-world-clis/` when you want examples of what you can build.

- `real-world-clis/create-app.ts`
- `real-world-clis/db-migrate.ts`
- `real-world-clis/deploy.ts`
- `real-world-clis/github.ts`
- `real-world-clis/release.ts`
