Visual primitives are small on purpose. Some return strings for composition.
Others print directly through the shared output system.

## Primitive overview

<TypeTable type={primitiveMethods} />

## Box

Use `cli.box()` to frame content in a titled section.

<Tabs items={['Code', 'Output']}>
  <Tab value="Code">
```ts
await cli.run(async () => {
  cli.box({
    title: "Deployment",
    content: "Ready to deploy to production.",
  });
});
```
  </Tab>
  <Tab value="Output">
```oscli
┌─ Deployment ───────────────────┐
│  Ready to deploy to production. │
└─────────────────────────────────┘
```
  </Tab>
</Tabs>

## Table

## Spinner

Use `cli.spin()` around one async operation.

<Tabs items={['Code', 'Output']}>
  <Tab value="Code">
```ts
await cli.run(async () => {
  await cli.spin("Installing packages", async () => {
    await new Promise((resolve) => setTimeout(resolve, 300));
  });
});
```
  </Tab>
  <Tab value="Output">
```oscli
⠸ Installing packages...   0.2s
✓ Installed packages       0.3s
```
  </Tab>
</Tabs>

If you do not pass `doneLabel`, `oscli` tries to convert common gerunds to a
past-tense completion label.

## Progress

Use `cli.progress()` when your work already has named steps.

<Tabs items={['Code', 'Output']}>
  <Tab value="Code">
```ts
await cli.run(async () => {
  const steps = ["Validate", "Build", "Finalize"] as const;

  await cli.progress("Running steps", steps, async (step) => {
    if (step === "Validate") {
      await new Promise((resolve) => setTimeout(resolve, 150));
    }

    if (step === "Build") {
      await new Promise((resolve) => setTimeout(resolve, 150));
    }

    if (step === "Finalize") {
      await new Promise((resolve) => setTimeout(resolve, 150));
    }
  });
});
```
  </Tab>
  <Tab value="Output">
```oscli
⠸ Running steps  [######--------------]  [00:01]   33%
✓ Running steps  [####################]  [00:03]  100%
```
  </Tab>
</Tabs>

Pass `{ style }` as the fourth argument to change the bar appearance.
Available styles: `"hash"` (default), `"line"`, `"steps"`, `"braille"`, `"block"`, `"gradient"`.

```ts
await cli.progress("Building", steps, fn, { style: "block" });
```

## Link

Use `cli.link()` for docs or support URLs. Renders as a clickable OSC 8 hyperlink in supported terminals, otherwise falls back to `label (url)`.

<Tabs items={['Code', 'Output']}>
  <Tab value="Code">
```ts

  cli.link("oscli docs", "https://github.com/aidankmcalister/oscli");
});
```
  </Tab>
  <Tab value="Output">
```oscli
oscli docs (https://github.com/aidankmcalister/oscli)
```
  </Tab>
</Tabs>

│  └─ package.json       │

  </Tab>
</Tabs>

## Code Frame

Use `cli.codeFrame()` to show errors with inline source annotation and an optional hint.

<Tabs items={['Code', 'Output']}>
  <Tab value="Code">
```ts
await cli.run(async () => {
  cli.codeFrame({
    file: "src/index.ts",
    line: 12,
    column: 5,
    message: "Type 'string' is not assignable to type 'number'",
    source: [
      "const port: number = process.env.PORT",
      "                     ^^^^^^^^^^^^^^^^",
    ],
    hint: "wrap with Number() or use parseInt()",
  });
});
```
  </Tab>
  <Tab value="Output">
```oscli
src/index.ts:12:5
✗ Type 'string' is not assignable to type 'number'
    11 │ const port: number = process.env.PORT
    12 │                      ^^^^^^^^^^^^^^^^
       │     ^^^^^^^^^^^^^^^^
  Hint: wrap with Number() or use parseInt()
```
  </Tab>
</Tabs>

<Callout type="info">
  **Composable** — `cli.table()` and `cli.tree()` return strings so you can pass
  them into other primitives (e.g. `cli.box({ content: cli.table(...) })`).

  **Display** — `cli.box()`, `cli.note()`, `cli.banner()`, `cli.diff()`,
  `cli.keyValue()`, `cli.leaders()`, `cli.codeFrame()`, `cli.divider()`, and
  `cli.link()` print to stdout immediately.
</Callout>
